# Пури — сайт грузинского ресторана

Концепт сайта для ресторана, сделал для портфолио. Ресторан вымышленный, но всё на странице работает по-настоящему.

**Что есть на сайте:**
- живой огонь на первом экране: WebGL-шейдер с шумом и искры на canvas;
- хачапури при прокрутке собирается и печётся по шагам (SVG с фильтрами: фактура теста, глянец сыра, тени), с температурой и таймером;
- горизонтальная лента меню, которая едет при обычной прокрутке страницы;
- меню по категориям с иллюстрациями блюд (всё нарисовано в SVG, без фотографий);
- корзина: доставка или самовывоз со скидкой, порог бесплатной доставки, оформление заказа;
- бронь стола на интерактивном плане зала: выбираешь дату, время и число гостей, подходящие свободные столы подсвечиваются;
- статус «открыто / закрыто» по реальному времени и график работы с выделенным текущим днём;
- адаптивная вёрстка под телефоны.

Один файл `index.html`: HTML, CSS и чистый JavaScript, без фреймворков и сборки.

Посмотреть: https://azer1xxx1337.github.io/puri/
